# Default English Text-to-Speech Voices

This document lists the default English TTS voices that come pre-installed with Windows and macOS operating systems. These voices are ready to use without any additional installation.

## Windows Default Voices

Windows includes the following English (United States) voices by default:

- **Microsoft Zira** (Female)
- **Microsoft David** (Male)

---

## macOS Default Voices

macOS includes the following English voices by default:

### United States
- **Samantha** (Female)
- **Alex** (Male)
- **Victoria** (Female)
- **Daniel** (Male)

### Regional Variants
- **Karen** (Female - Australian English)
- **Moira** (Female - Irish English)
- **Tessa** (Female - South African English)
